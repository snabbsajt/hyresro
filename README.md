# Hyresro

Svensk sajt om att inreda hyresrätt utan att riskera depositionen.

**Tagline:** Lägenheten i skick, depositionen i fred.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS

## Utveckling

```bash
npm install
npm run dev
```

## Bygg

```bash
npm run build
```
